Delulu Drinks ☕

"Sip the delusion."

A full-stack SaaS platform for cafe owners to manage their 
entire business — menu, orders, staff, memberships & analytics. 
Built with Next.js 14, TypeScript, Prisma, PostgreSQL & shadcn/ui.

Features:
- 🧋 Customer side — browse menu, place orders, memberships
- 📊 Owner dashboard — manage menu, orders, staff & analytics  
- 👥 Role-based access — owner, manager, staff, customer
- 🌙 Dark mode ready
- 📱 Mobile responsive

Tech Stack:
Next.js 14 · TypeScript · Tailwind CSS · shadcn/ui · Prisma · PostgreSQL · NextAuth.js
